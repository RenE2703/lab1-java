# Lab 1 Java

Bài lab 1 môn IT002.

Trong `src` có 7 bài cơ bản, bài Bristleback và các ví dụ đầu buổi.

Chạy bằng JDK 17:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 Exercise01EvenOdd
```

Đổi tên lớp cuối lệnh để chạy bài khác, rồi nhập dữ liệu trong terminal.
Bài tìm mảng dùng chỉ số từ 0. Hai mảng ở bài 7 cần được nhập theo thứ tự tăng dần.

Bristleback nhập lần lượt n, các thời điểm, x, y, z. Hai mẫu trong đề ra 580 và 2120.
